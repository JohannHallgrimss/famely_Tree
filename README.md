# Family Tree

A scalable React + TypeScript website that uses a JSON file as the data source for a family tree overview.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Notes

- The app uses a JSON dataset for persons and a modular layout that can support future pages and richer visualization.
- The table is sortable by name or birth date, and each row opens a modal with detailed information.
